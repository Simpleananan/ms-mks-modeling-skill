# v0.5 content-preservation map

The v0.4 line was rebuilt from the original uploaded package rather than from the earlier narrow rc1 rewrite. v0.5 is built on that preserved rc3 baseline and adds model-level discovery/mechanism layers without removing the restored workflow.

## Original capabilities explicitly preserved

- Orientation from incomplete prompts
- Target-paper reconstruction
- Build or complete
- Literature streams and recomposition
- Candidate generation and evaluation
- Research convergence
- Structure-triggered validation checks
- Evidence Critic pass
- Explain solution logic
- Repair and selective revision
- Shadow draft
- Math Display Gate and answer-projection discipline
- Resume/state verification rules
- Evidence depth D0–D4
- Source priority and scope
- Exemplar retrieval vs novelty screening
- PROCESS_EVIDENCE firewall
- Citation/provenance rendering
- Stakeholder statement classification
- Decision-node algorithm and blocking/nonblocking routing

## New v0.4 capabilities

- source/formal/claim truth separation
- provenance labels for load-bearing objects
- claim-driven source closure and material source acknowledgment
- dual-track author/source versus independent derivation
- earliest material divergence
- parameter-domain and feasible-set nonemptiness
- Boundary and Threshold Gate
- attained optimum versus supremum/infimum
- candidate substitution-back
- equilibrium and claim closure
- targeted falsification
- scoped solution certificates and `STALE` dependencies
- explicit paper/process retrieval roots
- Windows symlink/reparse-point containment
- optional `--verify-hash` incremental verification
- duplicate-skill diagnostics and deterministic tests

## Intentionally superseded items

- The old hidden `MKS_PROCESS_ROOT_NAMES` behavior is replaced by explicit `--process-root`.
- The old standalone runtime `PRIVACY.md` is superseded by enforceable data-boundary rules in `references/retrieval_contract.md`; the historical file is preserved under `docs/legacy/`.
- The old license that prohibited cloning/downloading/agent runtime is superseded because it conflicted with GitHub installation.
- The nested runtime directory is superseded by a repository-root Skill so clone/download yields one installable Skill and one `SKILL.md`.


## New v0.5 capabilities

- LOCAL versus MODEL/PAPER-WIDE scope routing
- research-object fit and model-architecture diagnostics
- breadth-first material/model census before proposition-focused audit in broad tasks
- canonical model map and cross-material consistency
- institution-to-model mapping and implementation-consistency checks when load-bearing
- claim-independent solution-space/regime discovery
- mechanism identification and mechanism falsification
- negative-space mechanism-benchmark reasoning when mechanism isolation is decision-relevant
- assumption-leverage mapping and load-bearing robustness targeting
- minimal-model challenge and result-desirability firewall
- cross-claim and formal-to-narrative scope synthesis
- hidden-defect behavioral tests that measure discovery gain rather than only instructed checking

The v0.4 certification layer remains intact; v0.5 changes what is discovered **before** certification, not the meaning of a scoped PASS/FAIL.
